# Iron Extraction

一个纯前端的第一视角摸金射击原型，包含：

- 第一视角移动与射击
- 可搜索物资箱
- 战利品背包与仓库
- 敌人巡逻与交火
- 多个撤离点与撤离结算
- 商店、补给、变卖战利品
- 小地图与全屏地图

## 运行

```bash
npm start
```

然后打开 `http://localhost:5531`。

## 构建

```bash
npm run build
```

静态站点会生成到 `dist/client`。

## 操作

- `WASD` 移动
- `鼠标` 视角
- `F` 开火
- `R` 换弹
- `Shift` 冲刺
- `Q` 使用医疗包
- `E` 搜索 / 撤离
- `M` 打开战术地图
- `C` 使用兵种技能
- `Esc` 退出指针锁定
